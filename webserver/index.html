Security Features

적용한 보안 설정

구축 과정에서 적용한 Nginx 보안 설정과 보호 기능입니다.

🛡️
응답 헤더 확인

보안 헤더 적용

X-Frame-Options, X-Content-Type-Options, Referrer-Policy를 HTTP 응답에 추가했습니다.

🔒
GET 200 / POST 405

HTTP 메서드 제한

정적 페이지에 필요한 GET과 HEAD만 허용하며 POST 등 불필요한 메서드는 405로 차단합니다.

🗂️
수정 차단 테스트

읽기 전용 마운트

HTML 파일을 Docker 볼륨의 읽기 전용 옵션으로 연결해 컨테이너 내부 수정 시도를 차단했습니다.

👁️
Server: nginx

버전 정보 노출 제한

server_tokens off 설정으로 일반 HTTP 응답의 Nginx 버전 표시를 제한했습니다.

🌐
내부 통신 확인

내부 네트워크 분리

웹서버는 backend-net에 연결하고 Firewall 컨테이너를 통해 내부 HTTP 통신을 검증했습니다.

⚙️
구성 검사 통과

설정 유효성 검사

nginx -t로 설정 문법을 검사하고 reload로 변경된 설정을 반영했습니다.
